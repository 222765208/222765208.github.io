# 2. User Stories and Tasks — Personal Reflection (STAR)

[← Back to Second Assessment](../index.md#agile-assessment)



## Situation

Shezz-App had several connected customer features, including bookings, hairstyle offers and loyalty rewards.

## Task

I needed to translate those features into understandable user requirements and technical tasks.

## Action

The backlog records 12 user stories and separates backend, frontend and UI/UX responsibilities. I linked the stories to proposed acceptance criteria, such as showing booking errors and offer responses.

## Result

The breakdown provides a clearer plan for implementation and review. I learned to describe what a user needs before deciding how to build it. These task allocations are plans and must not be mistaken for verified completion.
