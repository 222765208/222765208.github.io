Reflections (STAR Method)

Reflection 1: Coding My CV in Markdown

Situation: I needed to create my CV using Markdown on GitHub, which was unfamiliar to me at first.

Task: I had to format the CV so it looked clean, professional and easy to read.

Action: I practised Markdown syntax for headings, lists and spacing, previewed the changes and adjusted the layout until it was clear.

Result: I created a well-structured CV and improved my confidence using Markdown for future projects.

Reflection 2: Mock Interview Experience

Situation: I had to record a mock interview and answer interview questions on camera.

Task: I needed to present myself professionally, answer clearly and show confidence.

Action: I practised before recording, focused on clear speech and organised answers, and paid attention to tone and body language.

Result: I became more aware of my communication strengths and areas to improve, including reducing filler words and being more direct.

Reflection 3: Using GitHub Pages

Situation: I needed to publish my portfolio so it could be accessed as a live website.

Task: I had to deploy the portfolio and check that its content displayed correctly online.

Action: I followed the setup guidance, enabled GitHub Pages for the repository and checked the live site after making updates.

Result: I published my portfolio and gained practical experience with GitHub Pages and maintaining a public project.
